# NASRIN SOUN — Forex Academy

GitHub Pages ready website.

## Upload to GitHub
1. Create a new GitHub repository.
2. Upload **all files inside this folder** (not the ZIP itself).
3. Make sure `index.html` is in the repository root.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`.
7. Save and wait for GitHub Pages to publish.

The website includes the Home page, navigation, 12 video lessons, covers, links, and video player.

> Note: GitHub's individual file limit is 100 MB. The videos in this package should remain below that limit; if you later add larger videos, use Git LFS or host the videos externally.
