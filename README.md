# NASRIN SOUN — GitHub Pages

This version has **NO assets folder and NO videos folder**. All files are in the root so GitHub web upload is easier.

## Upload
1. Extract this ZIP.
2. Open the extracted folder.
3. Upload all files directly into the GitHub repository (do not upload the ZIP itself).
4. Go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

The website links and clickable Community / Telegram / Signal / Learning Forex / Facebook / YouTube areas are included.
